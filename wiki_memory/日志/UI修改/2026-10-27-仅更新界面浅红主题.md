# 仅更新界面浅红主题

## 目标与结果

用户要求取消卡片外围描边，并让整体UI采用醒狮浅红色。后续明确邮票与背景也不能改色，因此最终只调整参数面板和界面控件的颜色，保持邮票图稿、票纸、画廊底色、票面光影、周围阴影及参数值不变。

卡片按钮不再绘制绿色外围焦点框。键盘焦点仍可见，以卡片右上票角旁的小红点提示；非键盘交互没有额外描边。

## 验证

- 本机Chrome/SwiftShader：1440×900画廊/真实悬停/键盘焦点；390×844手机画面。焦点态`outline:none`，小红点`rgb(184, 93, 85)`；无浏览器或画廊诊断错误。
- 实际参数仍为背景`#fbf7f1`、暖光`#ffd198`、暗部`#4e5c3c`、周围阴影`#635e53`。八张静态票PNG与源码输出未变。
- 画面保存在[桌面UI](../../../artifacts/theme-update/desktop-ui-palette.png)、[悬停](../../../artifacts/theme-update/desktop-hover.png)、[键盘焦点](../../../artifacts/theme-update/keyboard-focus.png)、[手机UI](../../../artifacts/theme-update/mobile-ui-palette.png)。
- `node --test tests/parameters.test.js`与`npm run build`结果见`docs/validation.md`。

## 后续

等待用户反馈；继续遵守浅红只用于界面控件、邮票与背景保持原色的范围。
