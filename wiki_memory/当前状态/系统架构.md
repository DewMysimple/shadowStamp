# 系统架构

## 模块职责与边界

React提供语义按钮、参数面板、可访问性提示和WebGL失败后的DOM纸面回退；原生Three.js拥有一个renderer与统一RAF。`artwork.js`生成六种原创Canvas图稿，`StampMaterial.js`处理透明齿孔、虚化与票面明暗；静态印刷不能混称动态光照。`config.js`保存布局与聚焦目标，`motion.js`保存可中断反向的连续进度。

`SurfaceTexture.js`生成与印刷图稿无关的独立微细纸纹法线；`StampMaterial.js`默认surface模式只以这些浅法线、指针暖光、粗糙度与透明涂层改变照明。没有从文字/C形/岛形提取的高度，没有凸字、真实顶点位移或金属反射分支。全卡保留各自印刷色；这一实现是用户最终“只改光、压纹可以、浮雕金属不要”的产品选择。

`DappledLight.js`适配用户幽兰场景8算法，仍作为可选dappled斑驳投影模式，复用gallery的renderer和时钟，不额外拥有RAF或DOM事件；默认surface模式不运行其昂贵光学pass，背景仍保持静态纸纹。源E盘工程不作为写入目标（用户约束）。

## 数据流与依赖

1. `App`读取版本化本机参数，修改后传给`StampGallery.configure()`；参数合同集中在`parameters.js`，当前49字段、v2保存，兼容v1。仅未动过的旧工厂光影三元组(.55/.18/.25)迁移为当前(.8/.26/.45)，用户自定义和关闭开关保留；光学范围由同一schema派生。
2. gallery按输入计算局部指针、倾斜与聚焦进度；PerspectiveCamera的投影同时用于GPU和DOM matrix3d，使点击区域随真实四角变化。
3. 默认surface模式在票面采样独立法线，指针改变时更新，收敛后停止RAF；可选dappled模式才在活动时计算固定384×480 RT，目标上限24次/秒。材质dispose释放各自的法线纹理；不在每次hover时新建资源。
4. 回退模式仍可选票与退出，无法提供同样的WebGL光照。运行时不依赖远程图片/字体/CDN。

已选原生Three.js而非R3F/额外动画库，原因是现有共享renderer与单一可逆进度可完成交互，保留资源和坐标连续性。此为前轮Agent在授权范围内采用的实现选择，已有源码，不是用户指定某个渲染库内部结构。

## 运行与部署

依赖为React19.2.8、Three0.185.1、Vite8.2.2和本机Chrome/Playwright。`npm install`后`npm run dev`在127.0.0.1:4173提供本地服务；占用时以终端实际URL为准。`npm run build`生成`dist/`；`npm run preview -- --port 4174`预览构建。项目未配置远程托管，本轮不发布。

业务检查为`npm test`、`npm run test:browser`、`npm run test:light`、`npm run test:controls`、`npm run test:fidelity`；生产检查脚本`node scripts/verify-production.mjs`默认4174，可用PRODUCTION_URL覆盖；本轮使用4175通过4项，未停止原有4173/4174服务。按改动范围选择检查，不把命令存在当作执行结果。
