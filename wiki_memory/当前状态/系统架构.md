# 系统架构

## 模块职责与边界

根src/public保持八态原版，editions/regional有独立src/public/index/vite/package和对应测试、文档、证据。两者依赖版本相同，共享根node_modules；各有一个renderer/RAF及本地资源。唯一工程记忆仍为根wiki_memory。

## 数据流与依赖

1. runStart/runGo进入根目录调用启动器，分别选原版根与editions/regional为cwd，固定4173/4174并strictPort。
2. 启动器检查端口和真实源码身份；正确已运行版本复用并打开浏览器，不相符时明确失败、不杀进程、不换端口。
3. Vite根隔离/src和/assets路径，两版浏览器origin隔离localStorage。原版51字段无预设，新版52字段六算法；不互相迁移用户参数。
4. 根运行文件维持11d5049，新版src/public/index/vite维持74ba21c；新版package名称/dev和preview端口为隔离适配。

## 运行与部署

根npm ci安装共享依赖。runStart=4173，runGo=4174；两版build输出各自dist。根npm test验证原版与启动器；新版目录npm test及test:presets验证新版；scripts/verify-dual-editions.mjs验证同时运行、存储和源指纹。用户仅授权GitHub仓库推送，未部署网站。

## 证据与未核实项

2026-10-28两版unit各19和build通过，新版presets8通过；原版27文件与整合前相同、PNG一致。双服务报告在artifacts/dual-editions/。依赖/端口设计及实际Git合并见docs/dual-editions.md；真机性能未覆盖。
