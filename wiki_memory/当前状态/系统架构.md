# 系统架构

## 模块职责与边界

React负责语义按钮、面板、键盘与回退，原生Three.js只有一个renderer和共享RAF。`artwork.js`提供六种原创印刷与齿孔alpha；`SurfaceTexture.js`独立生成浅纸纹法线，不读取图稿高度。`motion.js`控制可中断反向的聚焦进度，`config.js`控制布局。

唯一`paperLight`路径结合浅法线、浅暖主灯/独立橙灯和RGB光图；无surface/dappled模式分支。`ncsLighting.js`集中原站已核实颜色/强度/非金属参数。保留本地图稿，没有原站高度/位移与完整RoomEnvironment/Neutral链；曝光在适配器中是响应增益，不能把同值说成完整物理渲染等同。

## 数据流与依赖

1. App读取参数，面板改值传给原地`configure()`；4组51字段，无预设。v2键带appearanceRevision4，旧外观首次升级为唯一开启效果，保留布局/交互；当前手调与关闭保存。
2. gallery用同一PerspectiveCamera矩阵生成GPU姿态与DOM命中四角，raycast局部UV驱动灯位与光域。
3. 光域珊瑚/苔绿RGB及alpha经过50采样颜色加权散焦，材质再mix桃橙底并以默认.26 multiply合成。离屏RT固定384×480、上限24fps；坐标密度按`26.7/(scale*sizeNorm)`随实际票面和DPR更新，不重分配RT。Voronoi中心固定.5，底层椭圆随指针。
4. `lightScale`为原站paintScale意义的光纹放大；`textureScale`为本地纸纹法线放大，二者独立。周围投影通过持久alpha和shader调色/浓度/柔化。背景票48tap虚化先mipmap预滤波，避免重复细轮廓。
5. 无活动、关灯/强度0或暂停且输入收敛后停帧；减少动态停流动/指针，卸载释放20张warm纹理与其他资源。无运行时远程图片/字体/CDN。

## 运行与部署

React19.2.8、Three0.185.1、Vite8.2.2，本机Chrome/Playwright。`npm run dev`默认4173，占用以实际端口为准；`npm run build`生成忽略的dist。生产可`npm run preview -- --port 4280 --strictPort`，未发布远端。

检查入口为`npm test`、`test:browser`、`test:light`、`test:controls`、`test:fidelity`；最后一项导向新单光14项检查。生产脚本以PRODUCTION_URL覆盖端口。具体本轮执行结果见validation，不能只凭命令存在宣称已通过。
