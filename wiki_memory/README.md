# 工程记忆导航

模式为 **standard**，由用户于2026-10-26明确选择“标准的工程记忆”。使用根目录唯一记忆根，不另建竞争入口。项目内工具版本3.2.1，Python仅使用标准库。

新会话先读[维护协议](AGENTS.md)，再读项目概览、当前约束、当前待办；仅在任务涉及结构或缺陷时补读架构、已知问题。当前上下文读过且未变化的页面直接复用。README只负责导航，不复制当前业务事实。

- [项目概览](当前状态/项目概览.md)
- [当前约束](当前状态/当前约束.md)

- [已知问题](当前状态/已知问题.md)
- [工作日志](日志/MOC_工作日志.md)

日常开发直接遵守本项目协议，无需重新加载个人Skill。按主题用 `rg` 检索状态和正式文档；需要来由再读日志。页面来源以工程根为基准，历史测试须结合其当时revision理解。

维护命令见协议“维护工具”；每轮有修改时，先同步相关记忆并检查，再完成本轮本地Git提交。无修改不制造空提交。详细授权边界见[当前约束](当前状态/当前约束.md)。
