# Independent visual review

实际检查 `http://127.0.0.1:4173/`，本机 Chrome/WebGL，1440×900与390×844。参照 `docs/reference/key-0.000s.jpg`、`key-0.505s.jpg`、`key-5.237s.jpg`；不是仅阅读代码得出的审查。六张截图记录此次审查时的实际版本，可能早于后续调参。

总体：桌面自由构图、三个主体票叠放、右下裁切、深场尺寸及中心位置已接近视频。手机独立构图能够展示六枚邮票，没有横向溢出或头部遮挡，主票是明确视觉中心；聚焦手机票完整可见，左右留白合理。背景长条和彩虹强度已在这一版本明显克制。优先做以下五项，不需要增添更多特效。

1. **Hover按视频增加景深，而非沿用当前站CSS的4px。** 此次桌面hover仍能读出Kensho C的硬边、辨认各票外轮廓，而视频非选中票更奶油般虚化。建议桌面1440宽下12–14px起调、手机6–8px；随主票状态持续插值。增加blur需要继续扩宽透明gutter，避免由原有1.16quad重现裁切。
2. **把标签放到整枚邮票最高点之上，并恢复参考字号。** 实测桌面胶囊129.56×23px、10px字，中心x≈893；主票中心x≈858。现位置来自旋转后top-mid，因此标签偏右约35px，并与邮票最高左角在y轴重叠约8px。视频胶囊约153×25px（换算1440宽），12px字，离最高纸边约18–22px。建议投影邮票四角，用minY−18作标签底边，以邮票centerX横向居中；desktop12px/16.8px行高、4px12px内边距。手机可10px，保持标签完整在屏幕内。
3. **加一层宽而淡的接触投影，减轻深色轮廓线。** 当前初态主要是很近的细暗边和窄投影，纸票有贴在屏幕上的感觉；视频静态就有更散的落影和轻微离地。建议保持现有近影，加一层约20–28px blur、y10–16px、alpha≈.10–.14的轮廓投影；hover再缓慢变散。不要给每张票加矩形box-shadow。
4. **手机返回操作文字与点击区域加大。** 目前右上BACK TO COLLECTION为7px、底部退出提示8px，真机上过小。建议返回9px、按钮min-height44px；底部提示9–10px，保留安静低对比。初始页小号辅助印刷文字可保持，六张票图案本身在手机初态不需要全部细字可读，点开后阅读即可。
5. **让Kensho大C回到平面印刷的几何语言。** 目前Georgia大C带衬线角，叠加圆形hairline后呈现明显的金属/立体弯曲；视频是平坦的粗几何C与细颗粒。建议用单个粗圆弧绘制C，再在C轮廓mask内添加细纹；只在印刷油墨内部做颗粒，减少大面积高光。它会让主票旁的第二视觉中心更接近收藏纸品，而不是另一个镭射主体。

邮票主面当前有较大的连续褶皱/山脊，但作为原创设计可以保留。若继续迭代，可让细密指纹状雕刻纹覆盖更均匀；这是次于以上交互层次的视觉差异。
