# 六种邮票光影

2026-10-28，用户明确要求保存六种不同算法、包含旧版与本工程新版并作艺术命名。这替代此前“不提供预设”的选择。保留12张地域邮票、原画廊、聚焦、指针和参数机制。

在参数控件的“邮票光影 → 光影预设”选择。默认仍为本工程新版“晴窗暖笺”，已有手调数据不会强制重置。选择其他预设会装入该算法的光影/纸纹原值；继续调节后显示“已微调”，可用“恢复此光影预设”恢复。画廊纸色、聚焦底色、布局、偏转、动画/跟随、光影启用状态与固定预览状态都保留。

| 艺术名称 | 持久化ID / GPU编号 | 算法与表现 |
| --- | --- | --- |
| 林隙旧笺 | legacy-multiply / 0 | 旧版彩色光图乘算，保留更深的苔色暗部、全场纸纹响应、固定纸面度量与旧法线种子27041。 |
| 晴窗暖笺 | local-add / 1 | 本工程新版局部加光；光斑外保留印刷颜色，明亮区域叠加橙暖光；法线种子17041。 |
| 晨雾透光 | screen / 2 | 滤色：按剩余高光空间提亮，暗墨透出柔光，亮部逐渐收束。 |
| 午后柔映 | soft-light / 3 | 柔光：弯曲中间调，光区提亮、暗区压深，浓色印刷仍有层次。 |
| 琥珀漫照 | diffuse-transmission / 4 | 指数吸收与漫散射：暗区指数衰减，暖光以有界渐近函数进入纸面。 |
| 暮色留白 | luminance / 5 | 亮度加深减淡：统一RGB增益并限制通道溢出，尽量保留印刷色相。 |

四种新增效果为显示RGB中的艺术合成，并非测量纸张的物理透射模型。它们与旧/新公式共用有机光场、浅纸纹与橙暖点灯，不是六套颜色或滑块别名。六种效果仅作用于交互邮票；未交互时或关闭光影后，图稿输出一致。背景保持静止，不加入金属、浮雕、位移或彩虹。

## 公式与适配边界

记印刷颜色为I、光场RGB为F、光场alpha为S、暖色为W、暗色为D、渐入强度为A、明暗强度为C、暗部深度为H。

- 旧版先累加全场纸面响应，再乘`mix(1, clamp(mix(W,F,S)+(1-D)*(1-H)*S,0,1), clamp(C*A,0,1))`。
- 新版使用`M=(1-S)^mix(1,1.7,H)`限制纸面响应，再加`mix(W,F,.72)*A*M*clamp(.55*C,0,.55)`。
- 滤色使用`1-(1-I)*(1-L)`，L由光图和纸面响应计算，限制在0到.85。
- 柔光根据有符号光场生成以.5为中性的混合值，分别使用暗部二次曲线与亮部开方曲线。
- 指数漫照使用`T=I*exp(-absorption)`及`T+(1-T)*(1-exp(-irradiance))`。
- 亮度塑形先计算目标亮度，再以单一增益缩放RGB，增益上限由最大颜色通道决定；最后仍有共用的微弱中性颗粒。

材质源码是完整系数的权威来源。旧版光场保持aspect .786、纸面度量(1,1.27)；其余五种按当前横/竖/超长票面适配。光场尺寸仍384×480，密度仍为`26.7/(lightScale*sizeNorm)`。两种纸纹法线预先创建并随材质释放，切换只改uniform，不分配纹理。当前12票共有50个上传纹理（12图稿、24法线、12阴影、2光场），以实际浏览器报告为准。

“旧版”保存的是旧算法，不替换当前印刷、纸色、尺寸或图稿里的既有光照；因此不承诺与旧Joy图稿截图相同。原站灯光研究仍见[ncs-light-source-audit.md](ncs-light-source-audit.md)，本轮四个新算法不是原站算法。

## 保存与验证

`lightPresets.js`保存六套不可变预设；`lightAlgorithm`是白名单枚举。选中算法、手调值与关闭状态一起存储/导出。存储键v2和appearanceRevision4继续兼容；以前revision4缺少算法时补为local-add，其他数值逐项保留。更早的银面/材质模式沿用既有迁移规则，不恢复。

- [同参六算法对比](../artifacts/light-presets/comparison.png)：固定同一票、时间、指针和参数，排除调色预设造成的差异。
- [六算法浏览器报告](../artifacts/light-presets/report.json)：8项通过，佛山/田阳各15对画面均不同；关闭后5120点RGB采样一致，32×32桌面像素静止，资源不重建，实际GPU编号0至5，保存/导出/导入/刷新、手机和减少动态通过。
- [历史算法逐像素等价](../artifacts/light-presets/baseline-equivalence.json)：同一合成印刷、光图与uniform输入，横/竖两种尺寸，当前分支对59890ef旧材质、旧版分支对桌面11d5049旧材质均0通道差异。此项隔离材质公式，不冒充不同图稿/不同光场的整站像素一致。

启动本地开发服务后运行`npm run test:presets`；可用VERIFY_URL、VERIFY_OUTPUT、CHROME_PATH指定地址、输出和Chrome。构建及其他回归结果见[validation.md](validation.md)。本机Chrome/SwiftShader结果不代表低端真机性能。
