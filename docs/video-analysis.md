## 元数据与检查范围

`ffprobe -show_format -show_streams` 实测：2912 × 1952，H.264 High，286 个视频帧；视频流时长 **5.255 秒**，最后显示帧 PTS **5.236667 秒**；容器及 AAC 音轨时长 **5.312 秒**。`r_frame_rate=56/1`，`avg_frame_rate=57200/1051 ≈54.424fps`，帧间隔不完全恒定，不能按固定 56fps 推导交互时间。

## 初始构图与材质

[原始初态帧](reference/key-0.000s.jpg) 是非居中的自由构图，上方约四成和左方大片留白，邮票集中右下方，边缘有刻意裁切。可见六枚独立设计。以下中心、角度、尺寸是依据图像边缘人工估计，误差约 1–2% 画幅、2–4°，不是原网页 CSS 测量；正角度表示顺时针。

主票初始未旋转纸张约 **13%W ×24%H**，宽高比约 0.78；旋转后的屏幕包围盒更宽，不能用包围盒宽直接计算放大倍数。聚焦终态纸张包围盒约 `(x=966…1826, y=434…1532)`，即宽 **29.5%W**、高 **56.3%H**，中心约 **(47.9%W,50.4%H)**，相对于初始线性尺寸放大约 **2.2–2.3 倍**。初始主票略在屏幕右侧，终态在屏幕中心稍左。

齿孔是纸张四边向内切出的半圆凹口，横边约 6 个，竖边约 8 个，纸角保留，内部没有透明孔。暖白纸边较宽，内绿区有细密等高线/防伪线，纸边在激活时也有浅粉、淡黄等反射。阴影柔软，静态时像离纸面很近的实物；hover 抬升后阴影更散。

核心空间转场约 **3.112–3.540秒，约428毫秒**。背景明显变暗稍晚于主票反应（约36毫秒），所有运动重叠发生。运动前段加速、后段迅速收敛，视觉上接近 ease-out，但无法由录屏唯一识别某个 easing 函数。实现应共享连续动画状态，同时插值位置、角度、尺寸、背景与非选中透明度；不应该分段顺序执行。

## 标签、提示和镭射特征

[Hover 高分辨率帧](reference/key-0.505s.jpg) 中标签为 **深棕黑色胶囊、暖白全大写等宽字体**，原文 `NEW CRAFT SOCIETY`。文字左右留白约一个字符，完整胶囊在源画面约310×50px，折算至1440宽约153×25px、字号约12px。它水平对齐主票中心，位于纸票顶部上方约18–22 CSS px（1440宽换算）；不随鼠标在票内到处移动，也没有证据表明它固定在屏幕上。

聚焦提示原文确实是 `CLICK ANYWHERE OR PRESS ESC.`，包括句点；小字号、全大写、等宽、低对比，接近底部中央，距离下边约1.9%H。中段已出现，和空间移动重叠，不能等所有动画结束才硬显示。

主票 hover 反射依赖鼠标位置，能够观察到绿、黄和浅粉暖色移动，但主要图案和文字仍清楚。不是整张票均匀叠加彩虹，绿色防伪线和纸边细纹是主体。视频本身无法判断是 GLSL、Fable、CSS 还是某个现有 shader；标题提及 Fable/Three.js 不能当作源码证据。

## 可确认与不能确认

视频直接确认：6枚可见邮票、原始裁切构图、主票上层遮挡、齿孔轮廓、hover时其他票模糊、深色胶囊标签、主票持续镭射反射、约0.43s并行聚焦、深色终态、底部退出提示。

视频没有包含：退出过程、重复点击、快速进出、移动端布局、resize、键盘行为是否真的有效，以及背景是否有树影形变。这些必须由网站观察或独立工程设计补充，不能声称来自这段视频。静态暖纸底纹可见；5秒片段内背景亮度很稳定，邮票阴影不能等同于独立斑驳光影系统。

当前网页研究的交叉验证结论由 `reference-websites.md` / `research.md` 记录；本文件只保留视频实测，不假装已经运行参考网站。
