# 邮票光影调节

只有一套默认开启的邮票光影，没有预设、材质模式或“场景8”选项。沿用用户选中的光斑形态，直接调节暖光、纸纹、暗部与虚化；保留原画廊布局、聚焦与面板。醒狮浅红色用于参数面板和界面控件；邮票图稿与画廊背景维持原色。允许浅纸面压纹，不做印刷图案凸起、几何位移或金属化。

暖感包含两层：独立橙色点灯，以及保留RGB的珊瑚／桃橙／苔绿光图；邮票的光影、暗部和周围投影默认值保持原样。[源码逐项对照](ncs-light-source-audit.md)、[灯光与环境实测](ncs-environment-source.md)记录原站来源和本地适配；[早期分析](single-light-audit.md)保留本轮研究过程。背景仍是原来的静态暖白纸面。

## 直接调什么

| 观察到的差异 | 控件 | 默认值与作用 |
| --- | --- | --- |
| 光图缺少局部橙色 | 暖光颜色 | `#ffd198`，对应原站光图peach；珊瑚中间色为`#ffaaa5`。独立点灯为`#ffe0b0 × .65`，不靠整票染黄 |
| 票面暗部偏色、太重 | 票面暗部深度、票面暗部颜色 | `1` / `#4e5c3c`，对应完整moss色；降低深度可减轻暗部 |
| 光图覆盖力度 | 光影强度、光图叠加强度 | `1` / `.26`；彩色光图按原站multiply关系混合 |
| 光纹大小不像参考 | 光纹放大 | `1×`，对应原站paintScale；越大光纹越大，按尺寸和DPR自动校正密度 |
| 纸纹大小不像参考 | 纸纹放大 | `.9×`；只缩放本地浅法线，不改变印刷或光图。它不等于原站paintScale |
| 纸纹明暗过重 | 细微压纹、纸面高光 | `.22` / `.45`；独立浅法线，不从字/C形提取高度 |
| 光带边缘生硬 | 散焦柔化 | `1.35`，只柔化光场，不模糊活动票的字和齿孔 |
| 周围投影偏色、太重 | 周围阴影颜色、浓度 | `#635e53` / `.44`，与票内暗部分开 |
| 周围阴影太硬 | 周围阴影柔化 | `1.4`，在既有软影上增加羽化，0保留基础接触软影 |
| 背景票不够失焦 | 其他邮票虚化 | `11px`，窄屏按 `6/11` 缩小 |
| 光斑方向与形态 | 覆盖、倾角、拉伸、散布、扭曲 | `.708 / 44° / .84 / 1 / .118`，覆盖值为原站半径的两倍 |
| 流动或跟随太快 | 流动速度、指针影响、跟随缓动 | `.35 / .85 / .16s` |

打开“固定光影预览”可以边操作面板边看最近一枚邮票；“聚焦主邮票”在暗场中检查细节。光斑与纸纹是同一效果的两个层次，所有显示的控件直接有效，不需要先切换模式。光图密度使用原站规则 `26.7 / (光纹放大 × clamp(560/半分辨率高度,1,3))`；固定384×480缓存只控制计算成本，不再固定视觉尺度。

原有几何交互保持：悬停/聚焦边缘偏转6°，透视距离1200/1400px，偏转缓动`.085s`，进入/返回`.46/.56s`。聚焦后移出默认保留最后姿态，面板可改为回正。第一次在面板按Escape收起面板，下一次退出聚焦。

快速切换邮票时，光影渐入与虚化恢复并行，不等待票面完全清晰；共享光图在新票首帧更新。`光影渐入/渐出`与`虚化缓动`的手调值仍独立有效；本次修复未重置保存值。持续流动按24fps预算，切卡/参数输入允许首帧立即刷新，见[实测](rapid-hover.md)。

## 保存与恢复

面板修改即时生效并自动保存在本机，支持单组/全部重置、复制、下载、导入或粘贴JSON。当前4组51字段，合同以 `src/parameters.js` 为准。重置直接回到唯一默认值。

存储键仍为 `postal-studies:parameters:v2`，导出带 `appearanceRevision:4`。旧v1/v2外观数据首次读取或导入时，将光影/形态升级为当前唯一开启效果，保留布局、偏转、转场与背景偏好；旧模式/密度字段会丢弃。当前revision的手调值、主动关闭开关准确保存，不反复覆盖。旧v1键不删除。非法字段忽略，数值夹在范围内，颜色只接受六位十六进制。禁止localStorage时仍可实时调节与导出。

减少动态时暂停光场流动、指针照明与几何偏转，颜色/形态仍能调节；输入收敛后停止RAF。正常动态只在交互邮票存在时运算384×480光场，上限24次/秒；移出后停止，背景没有光斑。参数修改不新建纹理或材质。无WebGL使用原有纸面回退。

程序化图稿与浅纸纹不是原站专用资产。点灯颜色/强度/高度和粗糙度/涂层等值取自实测；本地仍是保色浅纸纹适配器，没有原站专用高度、PMREM环境与完整Neutral输出链，曝光作为响应增益使用，不能据相同数值宣称整个物理渲染逐像素一致。当前运行结果与证据见[验收](validation.md)。
