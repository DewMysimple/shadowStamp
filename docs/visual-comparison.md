## 背景静止，光效限制在当前票面

最终 [hover截图](../artifacts/light-study/final-hover.png) 可直接看到：主票有柔边、斜向、有机的亮暗光区，纸面背景没有树影；非选中票主要通过虚化退后。场景8光场由当前邮票局部UV采样，再以纸张alpha限制在纸面及真实齿孔轮廓内，没有整屏光场覆盖。

对两边无文字、无邮票区域 `x=10%…90%W，y=15%…32%H` 重新采样。亮度Y采用0.2126R+0.7152G+0.0722B，范围0…255；百分位差只表示保存截图中的空间对比，不是显示器亮度或时间闪烁测量。

## 手机与保留差异

390×844采用独立自由构图。主票初态中心(57.5%W,35.5%H)、宽126.75px；聚焦中心(50%W,50%H)，尺寸280.80×357.25px，即72%W、42.33%H。[手机初态](../artifacts/verification/mobile-01-initial.png) 与 [手机聚焦](../artifacts/verification/mobile-04-focus.png) 使用最终截图。视频没有手机画面，此处是可用性设计，不虚构移动端还原分数。

仍存在的视觉差异：

- 六枚票面均为原创程序化设计；主票等高线和岛形分布不同，Specimen为植物版画而非原照片。没有复制原站品牌资产。
- 成品按最新要求呈现局部自然光，参考视频则有更明显的细密浮雕和暖色反射；不将两种光学表现混称为逐像素一致。
- 非选中票已明显失焦，少量边缘仍可见多采样叠影，比视频连续柔焦更有纹理；配置11px不等于视频高斯blur的精确测量。
- 成品齿孔更规则，纸边缺少部分视频里的不规则印刷细节；新增了轻量展览页眉和返回操作。

[14项全页浏览器检查](../artifacts/verification/browser-report.json) 与9项光场专项均使用最终前端。功能通过与视觉相同是两件事；本文明确保留差异，也没有把软件渲染表现当作真实低端手机GPU帧率保证。
